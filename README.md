# CodeAlpha Tasks

This repository contains three projects completed as part of the CodeAlpha internship tasks.

## Projects

1. **Transly - Language Translator** — A web application for translating text between languages.
2. **FAQ Chatbot** — A chatbot that answers frequently asked questions using text similarity.
3. **Object Detection and Tracking** — A computer vision project for detecting and tracking objects.

Each project has its own folder containing its source code and setup instructions.

## Technologies

Python, Flask, HTML, CSS, JavaScript, OpenCV, and machine learning libraries.
